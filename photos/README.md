# Ortsfotos

Ein Bild pro Zeile, genau unter dem angegebenen Dateinamen ablegen.
Fehlende Bilder werden in der App einfach weggelassen - du kannst also nach und nach befuellen.

Format: JPG, maximal 1200 Pixel breit, moeglichst unter 200 KB.
Das Repository ist oeffentlich: nur eigene Fotos oder frei lizenzierte Bilder
(z.B. Unsplash, Pexels, Wikimedia Commons). Keine Bilder aus der Google-Bildersuche.
